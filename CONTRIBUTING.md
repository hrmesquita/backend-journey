# Contributing

## Commits

Use [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/).

Format:

```text
<type>[optional scope]: <description>
```

Breaking changes may use `!` before the colon:

```text
feat(api)!: remove legacy endpoint
```

Examples:

```text
feat: add project filtering
fix(deploy): handle missing build directory
docs: update setup instructions
refactor(ui): simplify navigation state
test: cover project data mapping
chore: update repository tooling
```

Keep the subject concise and describe the change, not the implementation process.
